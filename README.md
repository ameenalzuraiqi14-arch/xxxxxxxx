# DevKit - Developer Toolkit

15 developer tools in one offline page: JSON, Base64/URL, JWT, Regex, Timestamps, Hashes, UUID/Password generators, Colors, Name converter, Diff, Text tools, HTTP codes, Git cheatsheet, chmod calculator and Snippets.

## Use it
- **Quickest:** double-click `index.html`. Works offline, no install, no server, no internet.
- **As an app (phone/tablet/desktop):** host the folder on any HTTPS site (GitHub Pages, Netlify) or run `python3 -m http.server` and open localhost. Then use "Install app" / "Add to Home Screen". It works offline afterwards.

Everything runs locally in your browser. Snippets are saved in your browser's localStorage.
